# TS-011 검색은 맞는데 답변이 이상하거나 앞부분 내용이 반영되지 않을 때

## 증상
- 오류는 없는데 답변이 검색된 문서 내용과 맞지 않는다.
- 로그나 긴 질문을 넣었을 때 앞부분 내용이 답변에 반영되지 않는다.
- 검색된 출처는 맞는데 지시한 답변 형식이나 규칙이 지켜지지 않는다.

## 영향 범위
- 검색 청크가 많거나 `logText`가 긴 operation·diagnosis 요청의 답변 품질.

## 가능한 원인
1. Ollama 컨텍스트 길이가 기본값 4096이면, 검색 청크·로그·프롬프트가 합쳐져 한도를 넘을 때 오류 없이 앞부분이 잘린다. 프롬프트 앞부분에 있는 지시와 근거가 사라질 수 있다.
2. 검색 결과 수(Top K)나 청크 크기가 커서 입력이 길어졌다.
3. 사용자가 입력한 로그가 너무 길다.

## 우선 점검 순서
1. `.env`의 `OLLAMA_CONTEXT_LENGTH`가 `8192`로 설정되어 있는지 확인한다.
2. 입력 길이에 영향을 주는 값을 확인한다: 검색 결과 수(Top K), `CHUNK_SIZE`, 입력한 `logText` 길이.
3. 짧은 질문으로 같은 문서를 검색했을 때는 답변이 정상인지 비교한다.

## 조치 방법
1. `OLLAMA_CONTEXT_LENGTH`를 `8192`로 설정하고 서비스를 다시 기동한다.
   ```bash
   docker compose up -d
   ```
2. 검색 결과 수를 줄이거나 `CHUNK_SIZE`를 줄인다. 청크 크기를 바꾸면 문서를 다시 적재한다(OP-005).
3. 로그는 오류가 나온 핵심 부분만 입력한다.

## 성공 확인 방법
- 같은 질문에서 답변이 검색된 근거와 일치하고 지시한 형식을 따른다.

## 예방 방법
- 컨텍스트 길이를 늘리면 메모리 사용과 응답 시간이 함께 늘 수 있으므로, 입력 길이와 함께 조정한다.
- 긴 로그는 요약하거나 핵심 줄만 넣도록 안내한다.
